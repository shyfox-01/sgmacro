The data.gov.sg catalogue snapshot is used to search dataset titles and identifiers.

The curated [policy file](../config/policy_events.yaml) is the twentieth input
object. Each event links to its official announcement; it is maintained separately
from API data. Source selections, cross-checks and excluded alternatives are
recorded in the [registry](../config/sources.yaml).
